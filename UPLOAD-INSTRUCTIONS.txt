JACOB POTTS PORTFOLIO — GITHUB PAGES

Files in this package:
- index.html
- style.css
- script.js
- resume.pdf

To publish:
1. Open your Jacob-Potts.github.io repository on GitHub.
2. Replace the existing index.html and style.css with these versions.
3. Add script.js and resume.pdf to the repository root.
4. Commit the changes to the branch used by GitHub Pages (usually main).
5. GitHub Pages should refresh automatically after the deployment completes.

The site is fully static and does not require npm, React, or a build step.
